Settings

Connecting GitHub is optional. Without it, the review page lists the public egovernments repos and their assignable people, with a limit of about 60 GitHub lookups an hour. With it, you also get private repos you can open, and a much higher limit.

The token is only used to read lists from GitHub. It is stored in this Chrome profile only (not synced) and is never put into an issue. Issues are still created by you on github.com.

Creating a token

Classic token (simplest): github.com/settings/tokens/new with the scopes repo (needed for private repos only) and read:org.

Fine-grained token: github.com/settings/personal-access-tokens/new, resource owner egovernments, repository permissions Metadata and Issues: read-only. The org may need to approve it.

If the egovernments org uses SAML single sign-on, authorise the token for it (Configure SSO next to the token).
